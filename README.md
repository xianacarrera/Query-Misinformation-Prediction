# Query Harmfulness Prediction (QHP)

This repository contains the code, data and results associated to the paper *Query Harfulness Prediction (QHP): a New Challenge for Safer Retrieval Systems*.

## Installation

First, clone the repository. Next, create two new environments from the `environment_qmp.yml` and `environment_qppmetrics.yml` files. Their default names are `qmp` and `qppmetrics`, respectively:

```bash
conda env create -f environment_qmp.yml
# To change the environment name:
# conda env create -f environment_qmp.yml -n new-name

conda env create -f environment_qppmetrics.yml
# To change the environment name:
# conda env create -f environment_qppmetrics.yml -n new-name
```

Finally, activate one of the environments:

```bash
conda activate qmp
conda activate qppmetrics
# Alternatively:
# conda activate new-name
```

## Usage

Once the installation is complete, you can run:

* `chatgpt.py`, to generate a controversy score for the queries in the datasets.
* `qpp_metrics.py`, to run the classical QPP predictors: avg IDF, max IDF, avg SCQ, max SCQ, avg ICTF, and SCS on the queries.
* `query_quality_classifier.py`, to generate a prediction using the confidence score of the [Query Quality Classifier](https://huggingface.co/dejanseo/Query-Quality-Classifier) model.

Due to differences between the Python version required to run Pyserini with this implementation and the one needed to run the Query Quality Classifier model, the `qpp_metrics.py` script must be executed with the `qppmetrics` environment, while the rest of the files use the `qmp` configuration.

## Resources

We provide the datasets used in this project, as well as the results of various prediction methods. Note that the controversy scores are not reproducible, since they were generated by an LLM (GPT-4).

We also include the *compatibility* scores for each query, calculated with two search systems (BM25 and MiniLM-L-12-v2), which were used as reference to compute Pearson, Kendall, and Spearman correlation coefficients against our predictions. The number of *harmful* documents in the rankings and the associated NDCG\@K scores were also considered, but were ultimately discarded due to their lack of variability.
